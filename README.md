# Hangwell — Print Studio

**From artwork to a ready Etsy listing.** Hangwell is a desktop app for people who sell
wall art: crop every print ratio, export 300 DPI print files, upscale with AI, create
mockups, social images and listing texts. It works **offline**: your artwork never
leaves your computer.

This repository only hosts the **installers and update information**.

## Download

Get the latest `Hangwell-Setup-<version>.exe` from the
[**Releases**](https://github.com/Hangwell/releases/releases) page and run it.
Once installed, Hangwell checks for new versions by itself and updates with one click.

**Requirements:** Windows 10 or 11 (64-bit). A Vulkan-capable graphics card makes the
AI upscale much faster, but it is not required. macOS version planned.
